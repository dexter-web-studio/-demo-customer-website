# Demo Customer Website

A polished one-page demo website for a fictional web design business called **Northline Studio**.

## Files
- `index.html` — page structure and content
- `styles.css` — complete responsive styling
- `script.js` — mobile navigation and scroll reveal animations

## Run locally
Open `index.html` in a browser.

## Deploy
This site can be deployed on Cloudflare, GitHub Pages, Netlify, Vercel, or any static host.

## Demo note
All business names, testimonials, and contact details are fictional.
